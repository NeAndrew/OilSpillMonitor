**Приложение для обнаружения и анализа распространения нефтяных пятен на основе спутниковых данных**

---

## Описание

**OilSpillMonitor** — приложение на языке программирования C++ с использованием фреймворка Qt Creator и QGIS API для автоматизированного мониторинга разливов нефти. Система интегрирует радиолокационные спутниковые снимки Sentinel-1 и гидрометеорологические данные для обнаружения и последующего прогнозирования распространения нефтяного пятна. 

---

## Основные возможности

- **Загрузка спутниковых данных:** интеграция с Copernicus API для поиска и загрузки снимков Sentinel-1 (SAR).  
- **Обнаружение нефтяных пятен:** с помощью компьютерного зрения (YOLO и RF-DETR-Seg) определение границ нефтяныого пятна на снимке.  
- **Моделирование распространения:** лагранжева модель переноса с учетом гидрометеоролгических данных. Проверка пересечения с береговой линией.
- **Экспорт результатов:** сохранение данных о распространении пята и визуализация на карте. Создание финального отчета.

---

## Используемый стек

- **Язык программирования:** C++  
- **GUI:** Qt
- **Библиотеки для работы с геоданными:** QGIS API, GDAL, SNAP (Geo Processing Tool)
- **Спутниковые данные:** Sentinel-1 (SAR) через Copernicus API  
- **Гидрометеорологические данные:** Open-Meteo API  
- **ОС:** Astra Linux 1.8

---

## Установка

1. Установите **Qt 5.15+**, **QGIS API**, **SNAP** и **GDAL**,.  
2. Склонируйте репозиторий проекта.  
3. Откройте проект в Qt Creator.  
4. Настройте пути к библиотекам.  
5. Соберите проект и запустите приложение.
