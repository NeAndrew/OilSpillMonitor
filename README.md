# OilSpillMonitor

**Приложение для обнаружения и анализа распространения нефтяных пятен на основе спутниковых данных**

---

## Описание

**OilSpillMonitor** — приложение на языке программирования C++ с использованием фреймворка Qt Creator и QGIS API для автоматизированного мониторинга разливов нефти. Система интегрирует радиолокационные спутниковые снимки Sentinel-1 и гидрометеорологические данные для прогнозирования траектории движения нефтяного пятна. Приложение обеспечивает точный анализ и визуализацию, позволяя отслеживать распространение разливов и оценивать потенциальное влияние на прибрежные зоны.  

---

## Основные возможности

- **Загрузка спутниковых данных:** интеграция с Copernicus API для поиска и загрузки снимков Sentinel-1 (SAR).  
- **Предобработка изображений:** фильтрация шумов, детекция границ нефтяных пленок.  
- **Моделирование распространения:** лагранжева модель переноса с учетом гидрометеоролгических данных. Проверка пересечения с береговой линией.
- **Экспорт результатов:** сохранение данных о распространении пята и визуализация на карте.  

---

## Используемый стек

- **Язык:** C++  
- **GUI:** Qt  
- **Библиотеки для работы с геоданными:** QGIS API, GDAL, SNAP (Geo Processing Tool)
- **Спутниковые данные:** Sentinel-1 (SAR) через Copernicus API  
- **Гидрометеорологические данные:** Open-Meteo API  
- **ОС:** Astra Linux 1.8

---

## Установка

1. Установите **Qt 5.15+**, **QGIS API**, **SNAP** и **GDAL**,.  
2. Склонируйте репозиторий проекта.  
3. Откройте проект в Qt Creator.  
4. Настройте пути к библиотекам QGIS и GDAL.  
5. Соберите проект и запустите приложение.
